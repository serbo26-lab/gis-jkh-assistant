# GIS ЖКХ Assistant Helper

Черновое расширение для Chrome / Edge.

Оно не хранит логин, пароль, cookies или данные сессии в файлах программы.
Команды выполняются непосредственно в уже открытой авторизованной вкладке
`https://lk.dom.gosuslugi.ru/`.

## Установка для тестирования

1. Распаковать ZIP Windows-сборки целиком.
2. Открыть страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку `browser-extension` из архива сборки.
6. Открыть личный кабинет ГИС ЖКХ и войти обычным способом.
7. Запустить `GIS-JKH-Assistant.exe`.

Расширение работает только пока открыта вкладка личного кабинета ГИС ЖКХ.


## Поддержание сессии ГИС ЖКХ

Пока одновременно выполняются три условия:

- запущен GIS ЖКХ Assistant;
- браузерный помощник подключен к локальной программе;
- открыта вкладка личного кабинета ГИС ЖКХ,

помощник раз в 8 минут выполняет штатный запрос продолжения сессии
`GET /auth/api/rest/services/auth/echo/`.

Это тот же запрос, который веб-интерфейс выполняет после кнопки
«Продолжить работу» в предупреждении об истечении сессии.

Если предупреждение уже успело открыться, помощник дополнительно пытается
нажать именно кнопку «Продолжить работу».

Автопродление прекращается, если закрыть GIS ЖКХ Assistant или вкладку ГИС ЖКХ.


## Планирование работ и услуг

Начиная с dev26 помощник также создает и обновляет планы работ и услуг по уже
размещенным перечням.

Приложение передает только локальное состояние плана: GUID размещенного перечня,
год, работы, помесячные количества и необязательные даты. Перед сохранением
помощник самостоятельно получает актуальный перечень и существующий план из
ГИС ЖКХ, после чего вызывает штатный endpoint
`PUT /workplanning/api/rest/services/save/workplan`.

Логин, пароль и cookies по-прежнему не передаются в настольное приложение.


## Фиксация работ и услуг

Начиная с dev27 помощник поддерживает помесячное размещение фактических
показателей. В dev28 версия помощника повышена до **0.1.7** и добавлена работа
с фотографиями и внеплановыми работами.

Для каждого месяца помощник самостоятельно получает отчетный период дома,
загружает текущее состояние фиксации и только затем вызывает штатный endpoint
`PUT /workplanning/api/rest/services/save/fixedworks`.

Фотографии сначала загружаются через
`/filestore/api/rest/services/filestore/uploadFile`, после чего их GUID
включается в соответствующую строку фиксации.

Внеплановые работы выбираются из справочника `OrganizationWork`. Помощник
проверяет, что выбранная работа отсутствует среди плановых строк периода.

При повторном сохранении сохраняются данные ГИС ЖКХ, которыми приложение не
управляет. Акты не редактируются на этапе фиксации и передаются обратно без
изменений; они будут использоваться в разделе «Оценка качества».
