# ГИС ЖКХ помощник

Текущая версия: **0.1.31**. Для приложения **dev57** используйте помощник 0.1.31 или новее. Обновление через мастер готовит новую папку: отключите прежнюю копию и загрузите новую. При ручной замене файлов в прежнем каталоге нажмите **«Перезагрузить»** на карточке.

В **0.1.31** исправлено сопоставление актов с одинаковыми номерами: резервный поиск после первого сохранения учитывает тип, дату регистрации и период. При нескольких совпадениях возвращается ошибка, а известный GUID акта имеет приоритет. Чтобы получить исправление, обновите файлы расширения; обновления только программы недостаточно.

Помощник сопоставляет выбранную в программе УО с организацией авторизованной вкладки по ОГРН и корневому GUID. Подтверждённая вкладка проверяется перед каждой командой; фокус другого окна не меняет её. Если нужный кабинет отсутствует или организация во вкладке изменилась, команда останавливается. Для добавления новой УО сделайте её вкладку активной в нужном окне браузера. При общей браузерной сессии ориентиром служит организация, которую возвращает ГИС, а не подпись вкладки. Автопродление сессии выполняется для всех открытых вкладок ГИС.

**ГИС ЖКХ помощник** — расширение для Chrome, Edge и Яндекс Браузера, которое связывает программу **ГИС ЖКХ Ассистент** с уже открытым личным кабинетом ГИС ЖКХ.

Расширение не требует ввода логина и пароля в настольной программе.

## Установка

В dev57 доступен встроенный мастер: **Настройки → Связь с ГИС ЖКХ → Установить браузерный помощник…**.
Он подготовит постоянную папку с файлами, поможет открыть страницу расширений Chrome, Edge или Яндекс Браузера,
скопировать путь и проверить связь. Добавление расширения в режиме разработчика выполняется в самом браузере.
Подготовленную папку нельзя удалять: браузер использует её файлы. При обновлении мастер сохраняет прежнюю папку;
отключите старую копию помощника и загрузите новую папку, а не перезагружайте старую карточку.
Яндекс может отключать расширение из внешнего источника после установки и перезапуска — включите его снова.

Ручная установка из ZIP-сборки также доступна:

1. Распакуйте ZIP-сборку **ГИС ЖКХ Ассистент**.
2. Откройте страницу расширений: `chrome://extensions/`, `edge://extensions/` или `browser://extensions/`.
3. Включите режим разработчика.
4. Выберите **«Загрузить распакованное расширение»**.
5. Укажите папку `browser-extension` из архива.
6. Откройте личный кабинет ГИС ЖКХ и войдите обычным способом.
7. Запустите **GIS JKH Assistant.exe**.

## Что делает помощник

Помощник используется программой для:

- загрузки и размещения перечней работ и услуг;
- создания и обновления планов;
- фиксации выполненных работ;
- работы с фотографиями и внеплановыми работами;
- оценки качества и актов;
- получения справочных данных, включая единицы измерения работ;
- получения реквизитов текущей управляющей организации для её добавления в программу;
- загрузки реестра домов текущей управляющей организации;
- получения открытых сведений о периоде управления домом и реквизитах договора;
- поддержания активной пользовательской сессии во время работы.

Помощник работает только когда открыт личный кабинет ГИС ЖКХ и запущена настольная программа.

Поддерживаются оба адреса личного кабинета: **my.dom.gosuslugi.ru** и **lk.dom.gosuslugi.ru**. Расширение должно быть установлено в том же браузере и профиле, где открыта авторизованная вкладка. В dev57 вкладка для обмена определяется по организации, выбранной в программе.

Версия 0.1.27 не распознавала **my.dom.gosuslugi.ru**. Для исправления обновите файлы помощника и нажмите **«Перезагрузить» (⟳)** на его карточке в разделе расширений. Если файлы распакованы в другую папку, подключите расширение из этой папки. Программу перезапускать не нужно.

Поддержание сессии выполняется каждые четыре минуты через существующий механизм активности страницы и авторизованный запрос. Ошибка продления отображается в программе; закрытая вкладка, закрытый браузер или уже завершённая авторизация требуют действий пользователя.

Кнопка **«Добавить УО из ГИС»** в dev57 требует помощника **0.1.30 или новее**. Получаются данные только текущей организации в открытом авторизованном кабинете. Изменения в самом кабинете этой командой не выполняются.

Текущая версия помощника: **0.1.31**.
