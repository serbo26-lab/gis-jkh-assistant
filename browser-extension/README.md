# GIS ЖКХ Assistant Helper

Черновое расширение для Chrome / Edge.

Оно не хранит логин, пароль, cookies или данные сессии в файлах программы.
Команды выполняются непосредственно в уже открытой авторизованной вкладке
`https://lk.dom.gosuslugi.ru/`.

## Установка для тестирования

1. Распаковать ZIP Windows-сборки целиком.
2. Открыть страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку `browser-extension` из архива сборки.
6. Открыть личный кабинет ГИС ЖКХ и войти обычным способом.
7. Запустить `GIS-JKH-Assistant.exe`.

Расширение работает только пока открыта вкладка личного кабинета ГИС ЖКХ.
