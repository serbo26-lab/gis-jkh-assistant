# ГИС ЖКХ помощник

**ГИС ЖКХ помощник** — расширение для Chrome и Edge, которое связывает программу **ГИС ЖКХ Ассистент** с уже открытым личным кабинетом ГИС ЖКХ.

Расширение не требует ввода логина и пароля в настольной программе.

## Установка

1. Распакуйте ZIP-сборку **ГИС ЖКХ Ассистент**.
2. Откройте страницу расширений Chrome или Edge.
3. Включите режим разработчика.
4. Выберите **«Загрузить распакованное расширение»**.
5. Укажите папку `browser-extension` из архива.
6. Откройте личный кабинет ГИС ЖКХ и войдите обычным способом.
7. Запустите **GIS JKH Assistant.exe**.

## Что делает помощник

Помощник используется программой для:

- загрузки и размещения перечней работ и услуг;
- создания и обновления планов;
- фиксации выполненных работ;
- работы с фотографиями и внеплановыми работами;
- оценки качества и актов;
- получения справочных данных, включая единицы измерения работ;
- поддержания активной пользовательской сессии во время работы.

Помощник работает только когда открыт личный кабинет ГИС ЖКХ и запущена настольная программа.

Текущая версия помощника: **0.1.16**.
