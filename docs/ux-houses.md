# UX и первая вкладка «Дома»

## Общий стиль

Интерфейс должен быть простым, нативным и визуально близким к Windows 11:

- спокойная светлая тема;
- мягкие контрасты;
- скругленные углы у кнопок, полей и карточек;
- аккуратные рамки и разделители;
- адаптация к изменению размера окна;
- скроллы во всех областях, где содержимое может выходить за пределы видимой области;
- стандартное поведение текстовых полей: выделение, копирование, вставка и контекстное меню;
- автоматическое сохранение изменений;
- переход между вкладками, карточками домов и УО не должен приводить к потере введенных данных.

## Основная навигация

1. Дома
2. Перечни работ и услуг
3. Планирование
4. Выполнение
5. Настройки

На первом этапе реализуется вкладка «Дома».

## Вкладка «Дома»

Верхняя панель содержит выбор управляющей организации и действия:

- Добавить УО
- Изменить УО
- Удалить УО
- Импорт из файла
- Добавить дом

Рабочая область разделена на две части:

- слева — поиск и список домов выбранной УО;
- справа — прокручиваемая редактируемая карточка выбранного дома.

Карточка дома содержит адрес, УО, источник записи, идентификаторы, количество жилых/нежилых помещений и служебный комментарий.

## Автосохранение

Изменения сохраняются через короткую задержку после редактирования. При смене дома, УО или закрытии приложения ожидающие изменения сохраняются немедленно. Пользователь видит ненавязчивый статус «Сохранено», «Сохраняется…» или «Ошибка сохранения».

## Импорт

Импорт выгрузки «Объекты жилищного фонда»:

1. анализирует фактическую структуру XLSX;
2. читает УО из наименования и ОГРН;
3. создает новую УО или обновляет существующую по ОГРН;
4. агрегирует строки помещений в карточки домов;
5. считает уникальные жилые и нежилые помещения;
6. показывает предварительное резюме перед записью в локальную базу.

Номер VERSION сохраняется как диагностическая информация и не используется как жесткий запрет импорта.
