## Сквозные истории (обязательно провести целиком)
1. **Первое размещение:** новая УО → дома → перечень → план → факт → качество. Проверить, когда UI подсказывает следующий шаг, а когда можно безопасно вернуться.
2. **Ежемесячная рутина:** уже размещённый перечень → текущий месяц → факт/фото → качество → следующий месяц с сохранением контекста.
3. **Исправление после ошибки:** тот же контекст → частичный период → ошибка отправки → возобновление и проверка результата.
4. **Исторические данные:** синхронизированный старый перечень/план → просмотр → ограничение изменения → безопасный выход.
5. **Массовая работа УО:** множество домов → подготовка/загрузка → контроль ошибочных домов → отчёт по результатам без вымышленного «успешно всё».

## Протокол одного прогона (заполнять)
- Scenario ID; версия/commit; источник проверяемого сценария.
- Роль, исходные данные (фиктивные), целевой результат, экран/разрешение/масштаб/тема.
- Пошаговый путь, фактические действия и переходы; итог SUCCESS / PARTIAL / FAILURE / NOT TESTED.
- Измеренные время, количество действий, возвратов, ошибок, просьб о помощи (**если не измеряли — «не измерено»**).
- Какие H1–H10 нарушены/выполнены, уровень доказанности, Nielsen severity/engineering priority.
- Условия приёмки и регрессионные тесты для исправлений.
