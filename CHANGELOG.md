# Changelog

## 0.1.0.dev5 — 2026-09-29

### Добавлено
- рабочая вкладка «Перечни работ и услуг»;
- выбор УО, дома и рабочего года;
- год по умолчанию берется из системной даты компьютера;
- поддержка годов начиная с 2015 года;
- новый перечень автоматически создается на полный выбранный год: 01–12;
- период перечня можно вручную изменить по месяцам и годам, изменения сохраняются автоматически;
- локальное хранение перечней отдельно по каждому дому и году;
- пользовательские шаблоны перечней в рамках УО;
- импорт пользовательского шаблона из XLSX ГИС ЖКХ;
- если основной лист XLSX пуст, шаблон формируется из встроенного в файл справочника «СпрРабУсл»;
- если XLSX уже заполнен, импортируются выбранные работы и введенные значения;
- шаблоны можно именовать, переименовывать и удалять;
- первый импортированный шаблон по умолчанию предлагается назвать «Базовый»;
- при создании перечня строки выбранного шаблона копируются в отдельный снимок, поэтому последующие изменения шаблона не меняют старые перечни;
- таблица работ с полями «Цена», «Объем», «Кол-во», «Стоимость»;
- значения строк перечня сохраняются автоматически;
- для числовых счетчиков включены кнопки «+ / −».

### Архитектура
- добавлены сущности пользовательских шаблонов, строк шаблонов, перечней и строк перечней;
- шаблон относится к УО, перечень относится к дому;
- перечень хранит собственный период и не зависит от периода исходного Excel после создания.

## 0.1.0.dev3 — 2026-09-29

### Исправлено
- ручное добавление управляющей организации;
