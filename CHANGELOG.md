# Changelog

## 0.1.0.dev14 — 2026-09-30

### Обмен с ГИС ЖКХ
- добавлен первый рабочий контур автоматической загрузки перечня в уже открытый личный кабинет ГИС ЖКХ;
- Windows-сборка теперь содержит папку `browser-extension` с помощником для Chrome/Edge;
- помощник выполняет команды непосредственно в открытой авторизованной вкладке ГИС ЖКХ и не сохраняет логин/пароль в приложении;
- добавлена кнопка «Загрузить в ГИС ЖКХ»;
- программа автоматически формирует XLSX из выбранного локального перечня, передает его в браузер, загружает в файловое хранилище ГИС ЖКХ и запускает импорт;
- после импорта программа пытается найти проект по GUID дома и точному периоду перечня;
- добавлена кнопка «Проверить статус в ГИС»;
- добавлена отдельная кнопка «Разместить информацию» с подтверждением;
- размещение и загрузка оставлены разными действиями.

### Статусы
- у локального перечня сохраняются GUID проекта ГИС, GUID загруженного файла и GUID задания импорта;
- сохраняются последний известный статус ГИС, время проверки и последняя ошибка;
- локальный статус меняется на «Проект в ГИС ЖКХ» при DRAFT и «Размещен в ГИС ЖКХ» при APPROVED;
- в карточке перечня отображается отдельная строка состояния ГИС ЖКХ.

### Интеграция с браузером
- приложение запускает локальный шлюз только на 127.0.0.1;
- расширение получает команды только от локального приложения;
- запросы к ГИС выполняются внутри уже открытой вкладки личного кабинета через штатный AngularJS-контекст страницы;
- пользовательские cookies и данные авторизации не сохраняются в локальной БД приложения.

### Сборка
- ZIP актуального GitHub Release теперь содержит:
  - `GIS-JKH-Assistant.exe`;
  - `browser-extension/`;
  - `VERSION.txt`.

## 0.1.0.dev13 — 2026-09-30

### Ленивое заполнение
- количество больше не фиксируется жестко числом месяцев периода;
- число месяцев периода используется только как предзаполнение по умолчанию;
- добавлено поле «Количество по умолчанию» и кнопка массового применения ко всем позициям;
- количество можно изменить отдельно в каждой строке;
- при повторном открытии формы ранее примененные индивидуальные количества сохраняются;
- для позиции с процентом больше 0 количество должно быть больше нуля;
- позиции с 0% по-прежнему остаются пустыми после применения расчета;
- пример: при годовом перечне значение по умолчанию 12, но для покоса травы можно установить 3 месяца.

## 0.1.0.dev12 — 2026-09-30

### Заполнение от планируемой суммы
- добавлен второй способ заполнения выбранного перечня: «Распределить от итоговой суммы»;
- расчет работает с любым количеством позиций выбранного пользовательского шаблона;
- пользователь вводит одну итоговую планируемую сумму и процент распределения для каждой позиции;
- форма показывает рассчитанную сумму по каждой строке до применения;
- расчет можно применить только когда сумма процентов составляет ровно 100%;
- позиции с 0% остаются пустыми;
- после применения используются допустимые для ГИС ЖКХ поля «Количество + Стоимость»;
- «Цена» и «Объем» очищаются автоматически;
- количество устанавливается по числу месяцев периода перечня: полный год = 12, 05–12 = 8, переходящий 06–05 = 12;
- итоговая сумма и проценты распределения сохраняются в локальной БД;
- при создании перечня на основе выбранного сохраненная плановая сумма и проценты копируются вместе с остальными данными;
- расчет выполняется одной транзакцией, без поочередного сохранения каждой ячейки.

### Расчет и округление
- суммы рассчитываются по формуле «итоговая сумма / 100 × процент»;
- денежные значения округляются до копеек;
- возможный остаток округления автоматически добавляется к позиции с наибольшим процентом, поэтому сумма строк всегда точно совпадает с итоговой;
- добавлены тесты на пример 100 000 руб. с распределением 10/6/13/10/9/12/18/22%.

## 0.1.0.dev11 — 2026-09-30

### Исправлено
- вкладка «Перечни работ и услуг» получила общий вертикальный и горизонтальный скролл;
- элементы страницы больше не должны исчезать за нижней границей окна;
- прежний «compact mode», который менял почти только шрифт, заменен трехуровневой адаптацией;
- минимальный размер главного окна уменьшен, но интерфейс при этом не сжимается бесконтрольно.

### Адаптивный интерфейс
- режим Normal используется для большого окна;
- режим Compact уменьшает шрифты, отступы и размеры элементов для среднего окна;
- режим Narrow дополнительно уменьшает плотность интерфейса и перестраивает компоновку;
- в Narrow список перечней и карточка выбранного перечня располагаются вертикально, а не сжимаются в две узкие колонки;
- кнопки внутри смысловых блоков переносятся на дополнительные строки;
- для страницы заданы минимальные рабочие размеры, после которых включается скролл вместо дальнейшего разрушения верстки;
- боковая навигация также меняет ширину в зависимости от размера окна;
- добавлен горизонтальный стиль скроллбара в том же визуальном стиле, что и вертикальный.

## 0.1.0.dev10 — 2026-09-29

### UX вкладки «Перечни работ и услуг»
- верхняя панель теперь разделена на понятные смысловые блоки: «Контекст», «Создание перечня» и «Обмен с ГИС ЖКХ»;
- действия больше не собраны в один хаотичный ряд;
- «Шаблоны пользователя» относятся только к составу/заготовкам перечней;
- создание нового перечня и создание на основе выбранного расположены рядом как связанные действия;
- формирование файла для ГИС ЖКХ вынесено в отдельный блок обмена;
- статус технического шаблона экспорта всегда виден пользователю.

### Шаблон экспорта ГИС ЖКХ
- добавлена отдельная кнопка «Загрузить / обновить шаблон экспорта»;
- перед выбором файла показывается объяснение, где получить шаблон: «Добавление перечня…» → любой дом → «Выгрузить шаблон»;
- технический шаблон загружается отдельно от пользовательских шаблонов перечней;
- шаблон сохраняется локально и повторно выбирать его при каждом формировании XLSX не нужно;
- той же кнопкой шаблон можно обновить, если его формат изменится в ГИС ЖКХ;
- «Сформировать XLSX» больше не открывает скрытый диалог выбора исходного шаблона;
- если технический шаблон еще не загружен, программа прямо указывает, какое действие выполнить.

### XLSX
- генератор дополнительно приближен к официальному файлу ГИС ЖКХ;
- houseGuid в официальных шаблонах теперь заменяется внутри существующей shared string, без смены типа ячейки B1;
- названия работ при наличии исходных shared strings записываются ссылками на уже существующие строки справочника;
- структура строкового справочника сохраняется ближе к тому, как сам ГИС ЖКХ формирует шаблон;
- сохранен fallback для корректных XLSX, в которых строки представлены не через sharedStrings.

### Данные
- добавлено постоянное хранилище настроек приложения для технического шаблона экспорта;
- настройка не привязана к конкретному дому или пользовательскому шаблону.

## 0.1.0.dev9 — 2026-09-29

### UX
- верхний блок вкладки «Перечни работ и услуг» перестроен на устойчивую сетку вместо одной сжимаемой строки;
- выбор УО и дома теперь занимает отдельные строки и не конкурирует по ширине с кнопками;
- основные действия распределены по двум строкам, поэтому не перекрывают выпадающие списки на узком окне;
- выпадающие списки получили отдельную область стрелки, hover/pressed-состояния и оформление списка в стиле остальных элементов Windows 11;
- месяцы периода имеют минимальную ширину и больше не должны схлопываться рядом с годом.

### Формирование файла для ГИС ЖКХ
- добавлена кнопка «Сформировать XLSX» для выбранного перечня;
- при импорте пользовательского шаблона исходный XLSX сохраняется локально отдельно от базы;
- старые шаблоны, созданные до dev9, один раз запросят исходный официальный XLSX при первом формировании файла;
- сформированный файл создается на основе исходного шаблона ГИС ЖКХ, а не пересобирается с нуля;
- в копии шаблона заменяются houseGuid, период «с/по» и строки перечня;
- остальные части XLSX, включая служебные XML-части, справочники и настройки, переносятся без изменения;
- в файл попадают только фактически заполненные строки;
- перед выгрузкой проверяется один из допустимых режимов: «Цена + Объем + Кол-во» либо «Кол-во + Стоимость»;
- числа с запятой нормализуются для XLSX;
- работа сопоставляется со справочником исходного файла прежде всего по GUID.

### Данные
- в локальной БД добавлена ссылка на сохраненную копию исходного XLSX шаблона;
- добавлена автоматическая миграция существующей базы без удаления пользовательских данных.
