# GIS ЖКХ Assistant

Локальное приложение для автоматизации рабочих операций управляющей организации в ГИС ЖКХ.

> Проект находится в активной разработке. Интерфейс и отдельные сценарии еще могут меняться.

Текущая тестовая версия: **0.1.0.dev26**.

## Что уже можно делать

На текущем этапе реализованы три основные рабочие вкладки:

- **Дома** — локальный реестр управляющих организаций и многоквартирных домов;
- **Перечни работ и услуг** — создание, заполнение, хранение и размещение перечней;
- **Планирование** — помесячное планирование работ по уже размещенным перечням и размещение/обновление плана в ГИС ЖКХ.

---

# 1. Вкладка «Дома»

Вкладка предназначена для формирования локальной базы управляющих организаций и домов, с которыми пользователь работает в ГИС ЖКХ.

## Управляющие организации

В верхней части вкладки выбирается текущая управляющая организация.

УО можно:

- добавить вручную;
- изменить;
- удалить;
- создать автоматически при импорте файла «Объекты жилищного фонда».

Для УО сохраняются, в частности:

- наименование;
- ОГРН;
- дополнительные служебные данные, если они были введены.

Все дома привязываются к конкретной управляющей организации. Если в программе заведено несколько УО, дальнейшая работа ведется в рамках выбранной организации.

## Добавление домов вручную

Дом можно добавить вручную кнопкой **«Добавить дом»**.

Основные данные карточки дома:

- адрес;
- GUID объекта жилищного фонда;
- HOUSEGUID ГИС ЖКХ;
- HOUSEGUID ФИАС;
- уникальный номер дома;
- кадастровый номер;
- площадь к начислению;
- количество жилых помещений;
- количество нежилых помещений;
- комментарий.

Введенные изменения сохраняются автоматически. Для обычного редактирования не требуется постоянно нажимать отдельную кнопку «Сохранить».

## Площадь к начислению и тарифы

В карточке дома есть блок **«Начисления»**.

Поле **«Площадь к начислению, м²»** хранится отдельно для каждого дома и используется как справочное значение для расчетов перечня.

Тариф хранится не как набор обязательных годовых периодов, а как **история изменений**. Пользователь указывает:

- тариф, руб./м² в месяц;
- дату, **с которой тариф начинает действовать**.

Дата начала поддерживает два формата:

- **ММ.ГГГГ**, например `08.2025` — внутри программы это означает начало с **01.08.2025**;
- **ДД.ММ.ГГГГ**, например `10.08.2025` — точная дата сохраняется без округления.

Дата окончания вручную не вводится. Тариф действует до дня перед следующим указанным изменением. Если следующего изменения нет, последний известный тариф продолжает действовать дальше. Для будущих разделов ГИС ЖКХ программа уже хранит фактические дневные границы периода, поэтому месячная запись `08.2025 — 07.2026` может быть представлена как **01.08.2025 — 31.07.2026**.

Например:

- 08.2020 → 22,00 руб./м²;
- 08.2021 → 23,00 руб./м²;
- 08.2025 → 24,00 руб./м².

Из этого программа понимает периоды автоматически:

- 22,00 действует с 08.2020 по 07.2021;
- 23,00 действует с 08.2021 по 07.2025;
- 24,00 действует с 08.2025 до следующего изменения.

Поэтому если в 2022, 2023 и 2024 годах тариф не менялся, отдельные строки за эти годы вводить не требуется: используется последнее указанное значение 23,00.

При добавлении следующего тарифа программа предлагает тот же месяц изменения и следующий год. Это удобно для договоров, где индексация обычно происходит в одном и том же месяце, но месяц и год можно изменить вручную.

Тарифы можно добавлять, изменять и удалять. После каждого изменения границы действия соседних тарифов пересчитываются автоматически.

На текущем этапе тарифная история используется для предзаполнения расчета планируемой суммы. Если весь период перечня покрывается одним фактически действующим тарифом, он подставляется автоматически. Если внутри периода перечня происходит реальное изменение тарифа, программа не подставляет один из тарифов произвольно: такой период требует расчета по частям. Отдельный расчет по нескольким тарифным отрезкам будет развиваться в логике планируемой суммы.

В дальнейшем эта же история тарифов сможет использоваться для размещения сведений о тарифах в ГИС ЖКХ.

## Импорт домов из файла ГИС ЖКХ

Для массового добавления домов используется кнопка **«Импорт домов из ГИС ЖКХ…»**.

Нужная выгрузка формируется в ГИС ЖКХ по пути:

**«Реестр объектов жилищного фонда» → «Выгрузить информацию»**.

ГИС ЖКХ формирует архив **«Объекты жилищного фонда.zip»**. Его нужно распаковать и выбрать XLSX-файл внутри архива. Именно этот XLSX используется для импорта домов в приложение.

Эта подсказка также отображается прямо на вкладке **«Дома»** и в подсказке кнопки импорта.

При импорте программа:

1. определяет управляющую организацию;
2. при необходимости создает ее по данным файла;
3. извлекает дома;
4. сохраняет адреса и идентификаторы домов;
5. подсчитывает количество уникальных жилых помещений;
6. подсчитывает количество уникальных нежилых помещений;
7. не переносит в локальный реестр полный список квартир, помещений и их кадастровых номеров.

Версия файла ГИС ЖКХ не проверяется жестко только по значению VERSION. Основное значение имеет фактическая структура файла и наличие необходимых данных.

## Массовое заполнение площадей и тарифов

После импорта домов можно сформировать собственный простой XLSX приложения кнопкой **«Шаблон площадей и тарифов…»**.

Файл содержит:

- лист **«Площади»** — адрес и поле «Площадь к начислению, м²»;
- лист **«Тарифы»** — один дом в одной строке и история тарифов вправо повторяющимися парами **«Действует с» / «Тариф, руб./м² в месяц»**;
- лист **«Инструкция»** с краткими правилами заполнения.

Адреса выбранной УО подставляются автоматически. В файле также хранится скрытый служебный идентификатор дома, поэтому при обычном сценарии программа не зависит от текстового совпадения адреса.

Пример широкого формата:

| Адрес | Действует с | Тариф | Действует с | Тариф | Действует с | Тариф |
| --- | --- | ---: | --- | ---: | --- | ---: |
| Братская, 6 | 08.2020 | 22 | 08.2021 | 23 | 10.08.2025 | 24 |

Количество пар не фиксировано жестко: импорт читает все корректные пары заголовков вправо. Пустую пару можно оставить между заполненными — она будет пропущена. Старые файлы dev23 в вертикальном формате, где один дом повторяется в нескольких строках и используется только первая пара `Действует с / Тариф`, также продолжают импортироваться.

Если Excel хранит дату как настоящую дату, но отображает ячейку форматом **ММ.ГГГГ**, программа сохраняет месячную точность. Например `08.2020` означает **01.08.2020**. Формат **ДД.ММ.ГГГГ** сохраняется как точная дата.

Если тариф не менялся, повторять одинаковое значение каждый год не обязательно. Но если такие одинаковые точки уже есть в исходной таблице, они импортируются корректно и не считаются реальным изменением тарифа при подборе тарифа для перечня.

После заполнения используется кнопка **«Импорт площадей и тарифов…»**. Перед применением программа показывает, сколько площадей будет обновлено, сколько новых точек тарифа будет добавлено и сколько существующих точек изменится. Совпавшие значения повторно не записываются. Если строку нельзя однозначно сопоставить с домом, импорт не применяется до исправления файла.

Удаление существующего тарифа простым удалением строки из XLSX намеренно не выполняется: массовый импорт добавляет или обновляет значения, а удаление остается отдельным явным действием в карточке дома.

## Список домов

Слева отображаются дома выбранной УО.

Можно:

- искать дом по адресу;
- выбирать дом для просмотра и редактирования;
- корректировать данные;
- удалить дом из локальной базы.

GUID объекта жилищного фонда особенно важен для дальнейшей работы: он используется при формировании файлов перечней для конкретного дома.

# 2. Вкладка «Перечни работ и услуг»

Вкладка предназначена для создания локальных перечней работ и услуг по каждому дому, их заполнения и последующего формирования XLSX для загрузки в ГИС ЖКХ.

## Общая логика работы

Обычный порядок действий:

1. выбрать управляющую организацию;
2. выбрать дом;
3. выбрать год нового перечня;
4. выбрать пользовательский шаблон состава работ;
5. создать новый перечень;
6. заполнить его вручную или через распределение от планируемой суммы;
7. один раз загрузить технический шаблон экспорта ГИС ЖКХ;
8. при необходимости сформировать XLSX для ручной загрузки;
9. либо подключить браузерный помощник и загрузить выбранный перечень в ГИС ЖКХ прямо из программы;
10. после появления статуса «Проект» отдельно выполнить «Разместить информацию».

## Период перечня

По умолчанию новый перечень создается на полный выбранный год:

- с января;
- по декабрь.

Например, при выборе 2026 года создается период:

**01.2026 — 12.2026**

После создания период можно изменить вручную.

Поддерживаются и переходящие периоды, например:

**06.2025 — 05.2026**

Все перечни выбранного дома отображаются в общем списке слева независимо от года создания.

## Пользовательские шаблоны перечней

Кнопка **«Шаблоны пользователя»** открывает работу с локальными шаблонами состава перечня.

Пользовательский шаблон — это набор работ и услуг, который затем можно использовать для разных домов.

Примеры возможных шаблонов:

- Базовый;
- 5 этажей;
- 9 этажей;
- дом с лифтом;
- дом с мусоропроводом;
- дом с вентиляцией;
- дом с дополнительными инженерными системами.

Шаблон можно импортировать из XLSX ГИС ЖКХ и задать ему собственное имя.

Важно: **пользовательский шаблон перечня и технический шаблон экспорта ГИС ЖКХ — разные сущности**.

## Создание перечня

Кнопка **«Создать новый перечень»** создает отдельный перечень для выбранного дома.

Строки выбранного пользовательского шаблона копируются в перечень как самостоятельный снимок. Поэтому последующее изменение шаблона пользователя не должно менять уже созданные старые перечни.

Также доступно действие **«Создать на основе выбранного»**.

Оно удобно, когда нужно взять уже заполненный перечень и создать похожий перечень для другого года, сохранив текущие значения и структуру.

## Ручное заполнение

В таблице доступны поля:

- Цена;
- Объем;
- Кол-во;
- Стоимость.

Для одной строки предусмотрены два допустимых варианта заполнения:

### Вариант 1

**Цена + Объем + Кол-во**

При использовании этого варианта поле **«Стоимость»** блокируется для редактирования.

### Вариант 2

**Кол-во + Стоимость**

При использовании этого варианта поля **«Цена»** и **«Объем»** блокируются.

Если заполнено только количество, программа пока не считает способ заполнения выбранным.

Значения сохраняются автоматически.

## Заполнение от планируемой суммы

Для предварительного планового перечня можно использовать форму **«Заполнение от планируемой суммы»**.

Такой сценарий удобен, когда известна общая планируемая стоимость работ.

Планируемую сумму можно получить двумя способами:

- ввести готовую сумму вручную;
- рассчитать ее в форме как **тариф × площадь × месяцы**.

Например: **25,04 × 395,6 × 12 = 118 869,89 руб.**

Если в самом перечне еще не сохранены собственные значения, форма автоматически пытается подставить данные из карточки дома:

- площадь — из поля «Площадь к начислению»;
- тариф — из тарифа, период действия которого полностью покрывает период выбранного перечня.

Если период перечня пересекает несколько разных тарифов и ни один тариф не покрывает весь период целиком, тариф автоматически не выбирается, чтобы не получить неверный расчет.

После применения расчета тариф, площадь и количество месяцев сохраняются уже вместе с перечнем и снова подставляются при следующем открытии формы. При создании перечня «на основе выбранного» эти значения также копируются.

В форме пользователь:

1. вводит готовую сумму или тариф, площадь и месяцы;
2. при расчете по формуле программа заполняет поле планируемой суммы;
3. введенное количество месяцев одновременно становится новым количеством по умолчанию;
4. задает процент распределения по каждой позиции;
5. при необходимости корректирует количество отдельно по строкам;
6. программа рассчитывает сумму каждой позиции;
7. после проверки расчет переносится в перечень.

Сумма процентов должна составлять **100%**.

### Проценты для шаблона

Если одинаковый шаблон используется для однотипных домов, распределение процентов можно сохранить один раз и повторно применять в других перечнях.

В окне **«Распределение планируемой суммы»** доступны две кнопки:

- **«Сохранить % для шаблона»** — сохраняет текущие проценты у шаблона, из которого создан перечень;
- **«Загрузить % для шаблона»** — подставляет ранее сохраненные проценты в текущий перечень.

Пример: для дома «Братский 6» пользователь один раз распределил проценты по шаблону «Базовый» и сохранил их. Для дома «Братский 7» достаточно создать перечень по тому же шаблону, открыть распределение и нажать **«Загрузить % для шаблона»**. Тариф и площадь при этом остаются данными конкретного дома, а проценты берутся из сохраненного распределения шаблона.

Сохранение допускается только когда сумма процентов равна 100%. Если состав старого перечня уже отличается от текущего состава шаблона, проценты автоматически не загружаются.

### Количество

Количество не фиксируется жестко.

По умолчанию программа подставляет количество месяцев периода.

Например:

- полный год — 12;
- май–декабрь — 8.

Это только предзаполнение.

Можно:

- массово изменить количество для всех строк;
- изменить количество отдельно в конкретной позиции;
- использовать количество месяцев из расчета «тариф × площадь × месяцы» как массовое предзаполнение.

При вводе процентов с клавиатуры нажатие **Enter** после заполнения ранее пустой ячейки переводит выделение на следующую пустую строку. Если пользователь исправляет уже заполненный процент, после Enter выделение остается на текущей ячейке.

Например, для большинства работ может остаться 12, а для сезонного покоса травы можно указать 3.

Для заполненных строк ленивого расчета используется схема:

**Кол-во + Стоимость**

Позиции с 0% остаются незаполненными.

## Технический шаблон экспорта ГИС ЖКХ

Перед первым формированием XLSX необходимо отдельно загрузить технический шаблон экспорта.

Для этого используется кнопка:

**«Загрузить / обновить шаблон экспорта»**

Как получить файл:

1. открыть личный кабинет управляющей организации в ГИС ЖКХ;
2. перейти в **«Добавление перечня оказываемых услуг, выполняемых работ по управлению многоквартирным домом…»**;
3. выбрать любой дом;
4. нажать **«Выгрузить шаблон»**;
5. сохранить XLSX;
6. выбрать этот файл в GIS ЖКХ Assistant.

Достаточно одного такого шаблона.

Программа сохраняет его локально и использует как техническую основу для формирования новых файлов.

Если формат шаблона в ГИС ЖКХ изменится, той же кнопкой можно загрузить его новую версию.

## Формирование XLSX для ГИС ЖКХ

После заполнения перечня нажмите:

**«Сформировать XLSX из выбранного перечня»**

Программа берет сохраненный технический шаблон и подставляет в него:

- GUID выбранного дома;
- период перечня;
- выбранные работы и услуги;
- цену;
- объем;
- количество;
- стоимость.

При этом внутренняя структура официального XLSX по возможности сохраняется без лишних изменений.

Сформированный файл можно загрузить в ГИС ЖКХ вручную.

## Автоматическая загрузка через браузер

В Windows-сборку входит папка **`browser-extension`** с тестовым помощником для Chrome/Edge.

Помощник нужен для того, чтобы приложение работало с уже открытым и авторизованным личным кабинетом ГИС ЖКХ. Логин и пароль в GIS ЖКХ Assistant не вводятся.

### Установка помощника

1. распаковать ZIP сборки целиком;
2. открыть `chrome://extensions` или `edge://extensions`;
3. включить режим разработчика;
4. нажать **«Загрузить распакованное расширение»**;
5. выбрать папку `browser-extension`;
6. открыть личный кабинет ГИС ЖКХ и войти обычным способом;
7. запустить GIS ЖКХ Assistant.

В блоке **«Обмен с ГИС ЖКХ»** должна появиться надпись о подключенном браузере.

Пока программа запущена и открыта авторизованная вкладка ГИС ЖКХ, браузерный помощник автоматически поддерживает сессию активной штатным запросом продолжения примерно раз в 8 минут. В интерфейсе программы это отображается как **«автопродление сессии: включено»**. При закрытии программы или вкладки ГИС ЖКХ автопродление прекращается.

### Загрузка перечня

Для выбранного локального перечня нажмите **«Загрузить в ГИС ЖКХ»**.

Программа:

1. формирует временный XLSX;
2. передает его открытому личному кабинету;
3. загружает файл в файловое хранилище ГИС ЖКХ;
4. запускает импорт;
5. ищет созданный перечень по GUID дома и точному периоду;
6. сохраняет найденный GUID проекта и статус.

Если импорт еще обрабатывается, позже можно нажать **«Проверить статус в ГИС»**.

### Размещение

Когда перечень найден со статусом **«Проект»**, размещение выполняется отдельной кнопкой:

**«Разместить информацию»**

Перед действием программа показывает подтверждение. Загрузка и размещение намеренно не объединены в одну операцию.

В локальной базе сохраняются:

- GUID проекта перечня в ГИС ЖКХ;
- GUID загруженного файла;
- GUID задания импорта;
- последний известный статус;
- дата последней проверки;
- последняя ошибка обмена.

# 3. Планирование работ и услуг

Раздел **«Планирование»** становится практически полезным после размещения перечня работ и услуг в ГИС ЖКХ. В списке доступны только локальные перечни со статусом **«Размещен в ГИС ЖКХ»** и сохраненным GUID перечня.

План хранится отдельно для связки:

**размещенный перечень + календарный год**.

Это соответствует структуре ГИС ЖКХ, где план ищется по `workListGuid` и `year`.

## Таблица плана

Для каждой работы отображаются:

- работа / услуга;
- количество из размещенного перечня;
- количество в плане за выбранный календарный год;
- январь — декабрь.

**Количество в плане** рассчитывается автоматически как сумма значений по месяцам.

Ячейки месяцев, которые не входят в период размещенного перечня, блокируются. Это особенно важно для переходящих периодов, например **06.2025 — 05.2026**.

## Количество и конкретные даты

В ГИС ЖКХ месячная запись содержит два независимых элемента:

- **количество**;
- необязательный список **конкретных плановых дат**.

Поэтому в приложении можно просто ввести число в ячейку месяца, например `1`, не выбирая дату.

Если нужны конкретные даты, выполните двойной щелчок по месячной ячейке. Откроется календарь, в котором можно добавить одну или несколько дат этого месяца.

Количество не может быть меньше числа выбранных дат. Например, при трех конкретных датах в месяце количество должно быть не меньше 3.

## Автоматическое распределение

Кнопка **«Распределить количество по месяцам»** берет количество из размещенного перечня и равномерно распределяет его по полному периоду перечня.

Типовой случай:

- период — январь–декабрь;
- количество в перечне — 12;
- результат — по **1** в каждый месяц.

Для переходящего периода распределение выполняется сразу по полному периоду, а на экране показывается соответствующая часть выбранного календарного года.

Автораспределение заменяет месячные количества выбранного года и очищает конкретные даты в этих месяцах, чтобы старые даты не остались привязанными к новому распределению.

## Очистка отдельных ячеек

Одну или несколько месячных ячеек можно выделить мышью и нажать **Del**.

Программа удаляет для выбранных ячеек сразу оба вида данных:

- количество;
- конкретные даты, если они были выбраны через календарь.

Это работает как для одной ячейки, так и для группы выделенных ячеек. Служебные колонки «Работа / услуга», «В перечне» и «В плане» клавишей Del не очищаются.

## Размещение и обновление плана в ГИС ЖКХ

При подключенном браузерном помощнике доступна кнопка:

**«Разместить / обновить план в ГИС ЖКХ»**

Программа передает локальный план в уже открытую авторизованную вкладку ГИС ЖКХ. Помощник:

1. получает актуальный размещенный перечень по его GUID;
2. проверяет, что перечень по-прежнему имеет статус **APPROVED**;
3. ищет существующий план по связке `workListGuid + year`;
4. сопоставляет строки локального плана со строками размещенного перечня;
5. создает новый план либо обновляет существующий штатным запросом:
   `PUT /workplanning/api/rest/services/save/workplan`;
6. возвращает GUID сохраненного плана приложению.

Для существующего плана используются его актуальные GUID и `lastUpdateDate`, полученные непосредственно из ГИС ЖКХ перед сохранением.

Важно: локальная таблица считается **полным желаемым состоянием выбранного года**. При обновлении существующего плана месячные значения в ГИС ЖКХ заменяются текущими локальными значениями. Поэтому пустая локальная ячейка означает отсутствие планового количества в этом месяце. Перед отправкой программа показывает отдельное подтверждение.

Конкретные даты передаются только если они выбраны. Если в месяце указано только количество, ГИС ЖКХ получает количество и пустой список дат — такой сценарий соответствует штатному интерфейсу.

После успешного сохранения в локальной базе сохраняются GUID плана, время синхронизации и состояние обмена.

# Где хранятся данные

Локальная база, пользовательские шаблоны и технические файлы не хранятся в Git-репозитории.

Обновление программы не должно удалять пользовательскую базу.

Реальные выгрузки ГИС ЖКХ, cookies, браузерные профили, сертификаты и другие пользовательские данные также не должны попадать в Git.
