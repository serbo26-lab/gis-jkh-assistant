# ГИС ЖКХ Ассистент

**ГИС ЖКХ Ассистент** — настольная программа для управляющих организаций, которая помогает вести данные по домам и выполнять повторяющиеся операции в ГИС ЖКХ.

Текущая тестовая версия приложения: **0.1.0.dev57**.
Текущая версия **ГИС ЖКХ помощника**: **0.1.31**.

## Что умеет программа

В программе доступны пять основных разделов:

- **Дома** — реестр домов, площади, тарифы и импорт сведений из ГИС ЖКХ;
- **Перечни работ и услуг** — создание и подготовка перечней по домам;
- **Планирование** — помесячное планирование работ по размещённым перечням;
- **Фиксация работ и услуг** — фактические показатели, фотографии и внеплановые работы;
- **Оценка качества** — акты, оценка качества, сохранение проектов, размещение изменений и аннулирование.

Программа хранит рабочие данные локально на компьютере пользователя.

## Единая логика интерфейса

В **dev54** рабочие разделы построены вокруг процесса: **контекст → текущий этап → рекомендуемое действие → состояние операции → рабочие данные**. Этапы показывают, где находятся данные: локально, проект в ГИС или размещено. Одна выделенная кнопка предлагает следующий шаг; недоступное действие сопровождается причиной.

В разделах **«Фиксация работ и услуг»** и **«Оценка качества»** есть отдельные команды для **выбранного месяца** и **доступного периода**. Доступный период включает только месяцы выбранного года, входящие в период перечня.

На вкладке **«Дома»** слева находятся поиск и реестр, справа — карточка с основными данными, идентификаторами, управлением, площадями и тарифами. Массовая синхронизация относится к УО. Удаление дома находится в отдельной области карточки.

В **dev56** УО можно добавить кнопкой **«Добавить УО из ГИС»**: программа получает реквизиты текущей организации из авторизованного кабинета, показывает их для проверки и сохраняет локально после подтверждения. Если такой ОГРН уже есть, новая копия не создаётся. Ручное добавление остаётся доступным отдельно.

Загрузка домов, сведений об управлении и перечней всей УО вынесена в видимый блок **«Загрузка из ГИС ЖКХ — вся управляющая организация»**. Ручное редактирование и работа с файлами находятся в отдельном блоке. На остальных страницах также разделены сетевые действия, локальное заполнение и резервные XLSX-сценарии. Команды раскрытия подписаны «Показать» или «Скрыть» с названием секции.

В **«Перечнях»** выбор существующего перечня отделён от раскрываемого блока создания. Состав занимает всю ширину; добавление, распределение, шаблоны и очистка находятся рядом с таблицей. Основной путь ведёт через проверку, подготовку проекта и размещение. Технический XLSX остаётся резервным способом; подготовка проекта использует существующий механизм импорта ГИС.

**«Планирование»** ведёт от размещённого перечня через распределение и проверку к размещению плана. **«Фиксация»** показывает состояние каждого месяца и область действия. **«Оценка качества»** различает локальную оценку, проект и размещение: проект сохраняется без актов, а акты проверяются перед размещением.

При включённом **«Общем выборе»** переход сохраняет УО, дом, перечень и год. Если выбранный перечень ещё не размещён или год недоступен в разделе, интерфейс объясняет это и ожидает выбора пользователя. Год в блоке создания нового перечня задаёт только новый объект.

Долгие операции показывают текущий месяц, прогресс и причину остановки. Продолжение очереди начинается с месяца ошибки. Во время обмена рабочий контекст и редактирование блокируются, чтобы ответ ГИС не применился к другому объекту.

В настройках доступны полноценные **светлая и тёмная темы** с общей системой цветов и SVG-иконками. Локальные правки сохраняются автоматически. Подробнее об аудите и архитектуре интерфейса: [UX dev54](docs/ux-dev54.md), [доступность и действия dev56](docs/ux-dev56.md).

Масштаб интерфейса **100%, 125% или 150%** выбирается в настройках и сохраняется. Размер текста и элементов меняется вместе; расположение действий подстраивается под доступную ширину. Заголовок окна Windows 10 переключается между светлым и тёмным режимом; Windows 11 также поддерживает точный цвет выбранной темы. Системные кнопки и обычное изменение размера окна сохраняются.

# Установка

## Windows

1. Откройте страницу последней тестовой сборки в разделе **Releases**.
2. Скачайте ZIP-архив.
3. Распакуйте архив в отдельную папку.
4. Запустите **GIS JKH Assistant.exe**.
5. Для автоматической работы с личным кабинетом установите расширение **ГИС ЖКХ помощник** через мастер в настройках или из папки `browser-extension`.

Логин и пароль от ГИС ЖКХ в программу вводить не требуется.

## Установка ГИС ЖКХ помощника

В dev57 появился мастер установки: **Настройки → Связь с ГИС ЖКХ → Установить браузерный помощник…**. Он подготовит папку расширения, откроет страницу расширений Chrome, Edge или Яндекс Браузера и поможет проверить подключение. Само расширение нужно добавить в браузере вручную.

Для ручной установки в Chrome или Edge:

1. откройте страницу расширений браузера;
2. включите режим разработчика;
3. выберите **«Загрузить распакованное расширение»**;
4. укажите папку browser-extension из архива программы;
5. откройте личный кабинет ГИС ЖКХ и авторизуйтесь;
6. запустите **ГИС ЖКХ Ассистент**.

В левом нижнем углу программы отображается состояние подключения.

Помощник поддерживает личный кабинет на **my.dom.gosuslugi.ru** и **lk.dom.gosuslugi.ru**. Установите его в том же браузере и профиле, где открыта авторизованная вкладка ГИС ЖКХ. Пока программа и вкладка открыты, помощник поддерживает сессию каждые четыре минуты.

Если старая версия сообщает «Вкладка ГИС ЖКХ не открыта» при входе через **my.dom.gosuslugi.ru**, обновите помощник из архива актуальной сборки. Поддержка этого домена появилась в 0.1.28, а добавление УО из ГИС требует **0.1.29 или новее**. Для dev57 требуется **0.1.31 или новее**. При обновлении через мастер отключите старую копию расширения и загрузите новую подготовленную папку. Если заменили файлы в уже подключённой папке, нажмите **«Перезагрузить» (⟳)** на карточке расширения. Перезапуск программы не требуется.

# Дома

Раздел **«Дома»** предназначен для ведения домов управляющей организации.

Чтобы добавить УО из кабинета, войдите в ГИС ЖКХ, выберите там нужную организацию и нажмите **«Добавить УО из ГИС»** в программе. Проверьте реквизиты и подтвердите локальное сохранение. После этого нажмите **«Загрузить все дома УО»**. Если организация уже добавлена вручную с тем же ОГРН, программа сохранит её дома и ваши реквизиты, обновив связь с ГИС.

Для дома можно хранить:

- адрес;
- площадь, используемую для расчётов;
- историю тарифов;
- начало и окончание управления домом;
- номер и дату договора управления;
- количество жилых и нежилых помещений;
- сведения, импортированные из ГИС ЖКХ;
- комментарий.

## Период управления и договор

В карточке дома можно указать начало управления, окончание управления, номер договора и дату договора.

Если дом управляется по настоящее время, поле окончания можно оставить пустым.

Сведения можно заполнить вручную или получить из открытых сведений ГИС ЖКХ кнопкой **«Обновить управление из ГИС»** в карточке выбранного дома.

Для выбранной управляющей организации можно выполнить массовое обновление сразу по всем домам кнопкой **«Загрузить управление всеми домами»** в верхнем блоке загрузки из ГИС. Во время операции показывается счётчик выполнения. Если у отдельных домов сведения были введены вручную, перед обновлением можно выбрать: сохранить ручные значения или заменить их данными ГИС ЖКХ.

Поле **«Окончание управления»** используется как дата, с которой дом уже не находится в управлении. Например, если указано 01.03.2022, последним месяцем для перечня будет февраль 2022 года.

Когда даты управления заполнены, программа не позволяет сохранить период перечня раньше начала управления или после его окончания. Если даты не указаны, период перечня пользователь определяет самостоятельно.

## Тарифы

Для одного дома можно хранить несколько тарифов с разными датами начала действия.

Если появляется новый тариф, предыдущий автоматически считается действующим до дня перед новым изменением.

При распределении планируемой суммы для перечня выбранного года программа подставляет тариф, который действует на **01.01 этого года**. Например, если тариф меняется в середине года, для перечня всё равно используется значение, действовавшее на 1 января.

## Сведения о МКД

Основной способ наполнения реестра — кнопка **«Загрузить все дома УО»**. Программа получает все страницы реестра домов текущей УО напрямую из открытого личного кабинета, сравнивает их с локальной базой и перед применением показывает количество новых, изменённых и неизменившихся домов.

Для загрузки используется штатная пагинация ГИС ЖКХ по 10 объектов на страницу. Программа последовательно получает все страницы до общего количества домов, которое сообщает ГИС ЖКХ.

При обновлении сохраняются локальные тарифы, периоды управления, перечни, планы и другие данные, которых нет в реестре объектов жилищного фонда.

Резервный способ — **«Импорт домов из XLSX…»**. После нажатия программа показывает, какую выгрузку ГИС ЖКХ нужно выбрать, а затем открывает диалог выбора файла.

# Перечни работ и услуг

Раздел позволяет создавать перечни для выбранного дома и года.

Перечень можно:

- загрузить из ГИС ЖКХ вместе с уже размещённым составом работ, периодом и значениями;
- создать пустым и добавить нужные работы из актуального справочника своей организации в ГИС ЖКХ;
- создать по сохранённому пользовательскому шаблону;
- удалить лишние работы до загрузки перечня в ГИС ЖКХ;
- скопировать на другой год;
- распределить планируемую сумму между работами;
- сохранить текущий состав как новый пользовательский шаблон;
- сформировать в XLSX;
- передать в ГИС ЖКХ через браузерного помощника.

На вкладке **«Перечни работ и услуг»** кнопка **«Загрузить перечни дома»** получает перечни только для выбранного дома. Массовая загрузка находится на вкладке **«Дома»**: **«Загрузить перечни всех домов»** в видимом блоке загрузки из ГИС. Для долгой загрузки показываются отдельные этапы получения, сопоставления и сохранения. Пока массовая операция выполняется, другие массовые действия не запускаются параллельно.

После загрузки размещенного перечня можно подтянуть уже существующие сведения из следующих разделов ГИС ЖКХ: **Планирование**, **Фиксация работ и услуг** и **Оценка качества**. Обратная загрузка выполняется точечно для выбранного перечня, года и месяца. Если локально уже есть данные, программа сначала просит подтверждение на замену.

Для старых периодов ГИС ЖКХ может не возвращать часть исторических работ в составе самого перечня, хотя они остаются в плане, фиксации или оценке. При обратной синхронизации такие строки сохраняются отдельно как исторические и не подменяются позициями из текущего справочника.

Старый размещенный перечень можно актуализировать без создания нового GUID. Сначала нажмите **«Отменить перечень в ГИС ЖКХ»**. После отмены программа очищает связанные локальные планирование/фиксацию/оценку и открывает состав для редактирования. Старые позиции можно удалить вручную либо кнопкой **«Очистить состав»**, затем добавить актуальные работы или полностью заменить состав выбранным шаблоном. Кнопка **«Сохранить изменения в ГИС ЖКХ»** сохраняет измененный состав как проект с тем же GUID, после чего его можно снова разместить.


Шаблон экспорта перечня можно получить автоматически кнопкой **«Получить / обновить шаблон из ГИС ЖКХ»**. Программа запускает официальный экспорт ГИС ЖКХ, дожидается готовности файла в реестре статусов обработки и сохраняет готовый XLSX. Ручной выбор файла оставлен как резервный вариант.

При добавлении работ программа показывает наименование, код, вид работы и единицу измерения из справочника организации. Уже добавленные позиции повторно выбрать нельзя.

Таблица работ и услуг располагается отдельным блоком на всю ширину раздела, чтобы длинные наименования и значения было удобнее просматривать и редактировать.

## Пользовательские шаблоны

Шаблон — это сохранённый набор работ конкретной управляющей организации. Его удобно создавать из уже собранного локального перечня кнопкой **«В шаблон…»**.

Перед созданием нового перечня по шаблону программа сверяет его состав с актуальным справочником организации в ГИС ЖКХ. Если часть работ больше недоступна, программа показывает их пользователю и предлагает создать перечень только из доступных позиций.

Для шаблона также можно сохранить процентное распределение планируемой суммы. Тариф и площадь при этом остаются данными конкретного дома.

## Распределение планируемой суммы

Программа помогает распределить рассчитанную сумму между строками перечня.

Для расчёта можно использовать:

- тариф дома;
- площадь;
- количество месяцев;
- сохранённые проценты по работам.

Полученные значения можно при необходимости изменить вручную.

# Планирование

Раздел **«Планирование»** работает с перечнями, которые уже размещены в ГИС ЖКХ.

Для каждого года можно указать:

- количество выполнений по месяцам;
- конкретные даты выполнения, если они нужны.

План можно разместить впервые или обновить позднее.

Перед обновлением существующего плана программа показывает подтверждение, чтобы пользователь понимал, что текущие локальные значения будут отправлены в ГИС ЖКХ.

# Фиксация работ и услуг

Фиксация ведётся по месяцам.

Для каждой плановой работы можно указать:

- цену факт.;
- объём факт.;
- количество факт.;
- стоимость факт.;
- фотографии.

Программа позволяет загрузить фиксацию из ГИС ЖКХ как за один месяц, так и последовательно за все доступные месяцы выбранного года. Размещение также доступно помесячно или очередью по заполненным месяцам.

## Фотографии

К работе можно прикреплять фотографии. Файлы, добавленные через программу, можно заменить или удалить при следующем размещении.

## Внеплановые работы

Можно добавить работу, которой не было в плане выбранного месяца.

Работа выбирается из справочника организации в ГИС ЖКХ. Наименование, вид работы и единица измерения берутся из этого справочника, а не из заранее заданного списка программы.

# Оценка качества

Раздел поддерживает как помесячную работу, так и полный цикл по всем доступным месяцам выбранного года. Проект оценки качества можно сохранить в ГИС ЖКХ без актов; требование наличия акта применяется только перед размещением. Это также позволяет удалить ранее загруженные акты, сохранить изменённый проект без них и затем добавить новые документы при необходимости.

Раздел поддерживает как помесячную работу, так и полный цикл по всем доступным месяцам выбранного года. Оценку можно сформировать по данным раздела **«Фиксация работ и услуг»**, загрузить из ГИС ЖКХ за один месяц или сразу за весь доступный период года, сохранить проекты года и последовательно разместить их в ГИС ЖКХ одной очередью.

При обычном акте выполненных работ поля **«Стоимость в ежемесячной плате»**, **«Дней ненадлежащего качества»** и **«Уменьшение платы»** остаются пустыми. Они используются только для ненадлежащего качества и перерасчёта. Фактическая стоимость для автоматически формируемого PDF берётся из раздела **«Фиксация работ и услуг»**, а не из поля оценки качества.

Для автоматического формирования стандартного акта программа использует фактические показатели того же месяца. Если к конкретной строке уже привязан пользовательский или импортированный акт, эта строка исключается из автоматического акта; существующий документ не удаляется и не перезаписывается. Повторная генерация заменяет только документы, ранее сформированные самой программой. Для исправления ошибочно заполненных полей перерасчёта есть очистка данных месяца и всех доступных месяцев года; включение работ и акты при этом сохраняются.

Раздел **«Оценка качества»** работает по месяцам размещённого перечня.

Для работы можно:

- включить её в оценку;
- указать стоимость в составе ежемесячной платы;
- указать количество дней ненадлежащего качества;
- добавить один или несколько актов;
- сохранить проект;
- разместить информацию;
- изменить уже размещённую информацию;
- аннулировать оценку.

## Акты

Поддерживаются:

- **акт выполненных работ**;
- **акт нарушения качества**.

Один акт можно применить сразу к нескольким работам.

В окне **«Акты месяца»** можно:

- добавить готовый файл;
- сформировать акт выполненных работ автоматически;
- применить акт к выбранным работам;
- применить акт ко всем включённым работам;
- изменить связи акта с работами;
- удалить акт.

## Автоматическое формирование акта выполненных работ

По умолчанию программа предлагает:

- номер акта — номер месяца;
- дату — последний день месяца;
- период — с первого по последний день месяца.

В PDF формируется таблица:

- № п/п;
- наименование работы или услуги;
- единица измерения;
- периодичность;
- стоимость факт.

Периодичность и фактическая стоимость берутся из раздела **«Фиксация работ и услуг»** за тот же месяц.

Единица измерения берётся из справочника работ и услуг организации в ГИС ЖКХ. Если единица для выбранных строк недоступна, пустая колонка в PDF не создаётся.

Если фактическая стоимость по какой-либо работе ещё не заполнена, программа предупреждает об этом перед формированием акта.

Автоматический генератор используется только для **акта выполненных работ**. Акт нарушения качества формируется пользователем самостоятельно.

# Настройки

В разделе **«Настройки»** можно выбрать способ работы с контекстом:

- **Независимый выбор** — каждый раздел сохраняет выбранный дом, перечень и год отдельно;
- **Общий выбор** — выбранный дом, размещённый перечень и год переносятся между разделами программы.

Общий режим удобен, когда пользователь последовательно работает с одним домом в разделах перечней, планирования, фиксации и оценки качества.

# Данные программы

Рабочая база, шаблоны и настройки хранятся в пользовательской папке программы и не удаляются при обычном обновлении версии.

При переходе со старых сборок папка данных с прежним названием переносится автоматически.

Перед экспериментами с новыми тестовыми версиями рекомендуется периодически делать резервную копию пользовательской папки программы.

# Обновление

Тестовые сборки публикуются в GitHub Releases.

Для обновления:

1. закройте программу;
2. скачайте новую сборку;
3. распакуйте её;
4. замените старые файлы программы;
5. если в описании версии указано обновление **ГИС ЖКХ помощника**, обновите папку расширения в браузере и нажмите **Reload / Перезагрузить**.

Локальная рабочая база при обычном обновлении сохраняется.
