# GIS ЖКХ Assistant

Локальное приложение для автоматизации рабочих операций управляющей организации в ГИС ЖКХ.

## Статус

Проект находится в активной разработке. Текущая версия: 0.1.0.dev1.

Первый функциональный этап:
1. импорт выгрузки «Объекты жилищного фонда»;
2. формирование локального реестра домов;
3. сохранение адреса и постоянного GUID объекта жилищного фонда;
4. подсчет уникальных жилых и нежилых помещений;
5. разбор шаблонов «Перечень работ и услуг»;
6. дальнейшая браузерная автоматизация личного кабинета УО.

## Базовые правила

- реальные выгрузки ГИС ЖКХ, браузерные профили, cookies, сертификаты и локальная база не хранятся в Git;
- неизвестная VERSION файла сама по себе не является ошибкой;
- импорт проверяет фактическую структуру и необходимые поля;
- данные пользователя хранятся отдельно от файлов программы;
- обновление программы не должно уничтожать пользовательские данные.

## Разработка

Требуется Python 3.12+.

    python -m venv .venv
    .venv\Scripts\activate
    python -m pip install -e ".[dev]"
    pytest
    python -m gis_jkh_assistant
