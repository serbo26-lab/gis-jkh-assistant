# GIS ЖКХ Assistant

Локальное приложение для автоматизации рабочих операций управляющей организации в ГИС ЖКХ.

> Проект находится в активной разработке. Интерфейс и отдельные сценарии еще могут меняться.

Текущая тестовая версия: **0.1.0.dev15**.

## Что уже можно делать

На текущем этапе реализованы две основные рабочие вкладки:

- **Дома** — локальный реестр управляющих организаций и многоквартирных домов;
- **Перечни работ и услуг** — создание, заполнение, хранение и формирование XLSX для последующей загрузки в ГИС ЖКХ.

Ниже описаны только эти две вкладки.

---

# 1. Вкладка «Дома»

Вкладка предназначена для формирования локальной базы управляющих организаций и домов, с которыми пользователь работает в ГИС ЖКХ.

## Управляющие организации

В верхней части вкладки выбирается текущая управляющая организация.

УО можно:

- добавить вручную;
- изменить;
- удалить;
- создать автоматически при импорте файла «Объекты жилищного фонда».

Для УО сохраняются, в частности:

- наименование;
- ОГРН;
- дополнительные служебные данные, если они были введены.

Все дома привязываются к конкретной управляющей организации. Если в программе заведено несколько УО, дальнейшая работа ведется в рамках выбранной организации.

## Добавление домов вручную

Дом можно добавить вручную кнопкой **«Добавить дом»**.

Основные данные карточки дома:

- адрес;
- GUID объекта жилищного фонда;
- HOUSEGUID ГИС ЖКХ;
- HOUSEGUID ФИАС;
- уникальный номер дома;
- кадастровый номер;
- количество жилых помещений;
- количество нежилых помещений;
- комментарий.

Введенные изменения сохраняются автоматически. Для обычного редактирования не требуется постоянно нажимать отдельную кнопку «Сохранить».

## Импорт домов из файла ГИС ЖКХ

Для массового добавления домов используется кнопка **«Импорт из файла»**.

Поддерживается выгрузка ГИС ЖКХ **«Объекты жилищного фонда»**.

При импорте программа:

1. определяет управляющую организацию;
2. при необходимости создает ее по данным файла;
3. извлекает дома;
4. сохраняет адреса и идентификаторы домов;
5. подсчитывает количество уникальных жилых помещений;
6. подсчитывает количество уникальных нежилых помещений;
7. не переносит в локальный реестр полный список квартир, помещений и их кадастровых номеров.

Версия файла ГИС ЖКХ не проверяется жестко только по значению VERSION. Основное значение имеет фактическая структура файла и наличие необходимых данных.

## Список домов

Слева отображаются дома выбранной УО.

Можно:

- искать дом по адресу;
- выбирать дом для просмотра и редактирования;
- корректировать данные;
- удалить дом из локальной базы.

GUID объекта жилищного фонда особенно важен для дальнейшей работы: он используется при формировании файлов перечней для конкретного дома.

# 2. Вкладка «Перечни работ и услуг»

Вкладка предназначена для создания локальных перечней работ и услуг по каждому дому, их заполнения и последующего формирования XLSX для загрузки в ГИС ЖКХ.

## Общая логика работы

Обычный порядок действий:

1. выбрать управляющую организацию;
2. выбрать дом;
3. выбрать год нового перечня;
4. выбрать пользовательский шаблон состава работ;
5. создать новый перечень;
6. заполнить его вручную или через распределение от планируемой суммы;
7. один раз загрузить технический шаблон экспорта ГИС ЖКХ;
8. при необходимости сформировать XLSX для ручной загрузки;
9. либо подключить браузерный помощник и загрузить выбранный перечень в ГИС ЖКХ прямо из программы;
10. после появления статуса «Проект» отдельно выполнить «Разместить информацию».

## Период перечня

По умолчанию новый перечень создается на полный выбранный год:

- с января;
- по декабрь.

Например, при выборе 2026 года создается период:

**01.2026 — 12.2026**

После создания период можно изменить вручную.

Поддерживаются и переходящие периоды, например:

**06.2025 — 05.2026**

Все перечни выбранного дома отображаются в общем списке слева независимо от года создания.

## Пользовательские шаблоны перечней

Кнопка **«Шаблоны пользователя»** открывает работу с локальными шаблонами состава перечня.

Пользовательский шаблон — это набор работ и услуг, который затем можно использовать для разных домов.

Примеры возможных шаблонов:

- Базовый;
- 5 этажей;
- 9 этажей;
- дом с лифтом;
- дом с мусоропроводом;
- дом с вентиляцией;
- дом с дополнительными инженерными системами.

Шаблон можно импортировать из XLSX ГИС ЖКХ и задать ему собственное имя.

Важно: **пользовательский шаблон перечня и технический шаблон экспорта ГИС ЖКХ — разные сущности**.

## Создание перечня

Кнопка **«Создать новый перечень»** создает отдельный перечень для выбранного дома.

Строки выбранного пользовательского шаблона копируются в перечень как самостоятельный снимок. Поэтому последующее изменение шаблона пользователя не должно менять уже созданные старые перечни.

Также доступно действие **«Создать на основе выбранного»**.

Оно удобно, когда нужно взять уже заполненный перечень и создать похожий перечень для другого года, сохранив текущие значения и структуру.

## Ручное заполнение

В таблице доступны поля:

- Цена;
- Объем;
- Кол-во;
- Стоимость.

Для одной строки предусмотрены два допустимых варианта заполнения:

### Вариант 1

**Цена + Объем + Кол-во**

При использовании этого варианта поле **«Стоимость»** блокируется для редактирования.

### Вариант 2

**Кол-во + Стоимость**

При использовании этого варианта поля **«Цена»** и **«Объем»** блокируются.

Если заполнено только количество, программа пока не считает способ заполнения выбранным.

Значения сохраняются автоматически.

## Заполнение от планируемой суммы

Для предварительного планового перечня можно использовать форму **«Заполнение от планируемой суммы»**.

Такой сценарий удобен, когда известна общая планируемая стоимость работ, например рассчитанная как:

**тариф × площадь**

В форме пользователь:

1. вводит общую планируемую сумму;
2. задает процент распределения по каждой позиции;
3. при необходимости указывает количество;
4. программа рассчитывает сумму каждой позиции;
5. после проверки расчет переносится в перечень.

Сумма процентов должна составлять **100%**.

### Количество

Количество не фиксируется жестко.

По умолчанию программа подставляет количество месяцев периода.

Например:

- полный год — 12;
- май–декабрь — 8.

Это только предзаполнение.

Можно:

- массово изменить количество для всех строк;
- изменить количество отдельно в конкретной позиции.

Например, для большинства работ может остаться 12, а для сезонного покоса травы можно указать 3.

Для заполненных строк ленивого расчета используется схема:

**Кол-во + Стоимость**

Позиции с 0% остаются незаполненными.

## Технический шаблон экспорта ГИС ЖКХ

Перед первым формированием XLSX необходимо отдельно загрузить технический шаблон экспорта.

Для этого используется кнопка:

**«Загрузить / обновить шаблон экспорта»**

Как получить файл:

1. открыть личный кабинет управляющей организации в ГИС ЖКХ;
2. перейти в **«Добавление перечня оказываемых услуг, выполняемых работ по управлению многоквартирным домом…»**;
3. выбрать любой дом;
4. нажать **«Выгрузить шаблон»**;
5. сохранить XLSX;
6. выбрать этот файл в GIS ЖКХ Assistant.

Достаточно одного такого шаблона.

Программа сохраняет его локально и использует как техническую основу для формирования новых файлов.

Если формат шаблона в ГИС ЖКХ изменится, той же кнопкой можно загрузить его новую версию.

## Формирование XLSX для ГИС ЖКХ

После заполнения перечня нажмите:

**«Сформировать XLSX из выбранного перечня»**

Программа берет сохраненный технический шаблон и подставляет в него:

- GUID выбранного дома;
- период перечня;
- выбранные работы и услуги;
- цену;
- объем;
- количество;
- стоимость.

При этом внутренняя структура официального XLSX по возможности сохраняется без лишних изменений.

Сформированный файл можно загрузить в ГИС ЖКХ вручную.

## Автоматическая загрузка через браузер

В Windows-сборку входит папка **`browser-extension`** с тестовым помощником для Chrome/Edge.

Помощник нужен для того, чтобы приложение работало с уже открытым и авторизованным личным кабинетом ГИС ЖКХ. Логин и пароль в GIS ЖКХ Assistant не вводятся.

### Установка помощника

1. распаковать ZIP сборки целиком;
2. открыть `chrome://extensions` или `edge://extensions`;
3. включить режим разработчика;
4. нажать **«Загрузить распакованное расширение»**;
5. выбрать папку `browser-extension`;
6. открыть личный кабинет ГИС ЖКХ и войти обычным способом;
7. запустить GIS ЖКХ Assistant.

В блоке **«Обмен с ГИС ЖКХ»** должна появиться надпись **«Браузер: ГИС ЖКХ подключен»**.

### Загрузка перечня

Для выбранного локального перечня нажмите **«Загрузить в ГИС ЖКХ»**.

Программа:

1. формирует временный XLSX;
2. передает его открытому личному кабинету;
3. загружает файл в файловое хранилище ГИС ЖКХ;
4. запускает импорт;
5. ищет созданный перечень по GUID дома и точному периоду;
6. сохраняет найденный GUID проекта и статус.

Если импорт еще обрабатывается, позже можно нажать **«Проверить статус в ГИС»**.

### Размещение

Когда перечень найден со статусом **«Проект»**, размещение выполняется отдельной кнопкой:

**«Разместить информацию»**

Перед действием программа показывает подтверждение. Загрузка и размещение намеренно не объединены в одну операцию.

В локальной базе сохраняются:

- GUID проекта перечня в ГИС ЖКХ;
- GUID загруженного файла;
- GUID задания импорта;
- последний известный статус;
- дата последней проверки;
- последняя ошибка обмена.

# Где хранятся данные

Локальная база, пользовательские шаблоны и технические файлы не хранятся в Git-репозитории.

Обновление программы не должно удалять пользовательскую базу.

Реальные выгрузки ГИС ЖКХ, cookies, браузерные профили, сертификаты и другие пользовательские данные также не должны попадать в Git.
