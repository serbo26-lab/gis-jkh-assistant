# Windows build

Готовые тестовые сборки не хранятся в Git как бинарные файлы.

Актуальная Windows-сборка автоматически публикуется в GitHub Releases:

- Release: `dev-latest`
- Архив: `GIS-JKH-Assistant-windows.zip`
- Внутри архива: `GIS-JKH-Assistant.exe`

Стабильная страница текущей тестовой сборки:

https://github.com/serbo26-lab/gis-jkh-assistant/releases/tag/dev-latest

Прямая ссылка на актуальный ZIP:

https://github.com/serbo26-lab/gis-jkh-assistant/releases/download/dev-latest/GIS-JKH-Assistant-windows.zip

При каждом успешном Windows-билде ветки `main` архив в `dev-latest` заменяется новой версией.
